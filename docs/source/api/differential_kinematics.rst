Differential Kinematics
=======================

The :mod:`moro.differential_kinematics` module provides task-space Jacobian
selection, forward Cartesian velocity propagation, numerical velocity-level
inverse kinematics, singularity diagnostics, condition-number analysis, and
Yoshikawa velocity manipulability.
