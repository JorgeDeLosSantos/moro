Trajectory Generation
=====================

The :mod:`moro.trajectory` module provides numerical point-to-point
trajectory generation and (starting in 0.7.0 PR-A2) piecewise-linear, cubic Hermite, and quintic Hermite
multi-waypoint trajectories in joint and Cartesian position spaces.
The shape-preserving cubic derivative policy is planned for PR-A4.
