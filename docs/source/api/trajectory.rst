Trajectory Generation
=====================

The :mod:`moro.trajectory` module provides numerical point-to-point
trajectory generation and (starting in 0.7.0 PR-A2) piecewise-linear
multi-waypoint trajectories in joint and Cartesian position spaces.
Cubic and quintic multi-waypoint methods are planned for PR-A3.
